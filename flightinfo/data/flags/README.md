Country flags for the weekly posts' pictures (ZenithBoard 0.36.1), 48 x 32 pixels, one PNG per ISO 3166 code.

Made from country-flag-icons by @catamphetamine (https://gitlab.com/catamphetamine/country-flag-icons, MIT
licence, see LICENSE), the 3:2 SVG set as tar1090 ships it (html/flags/3x2), rasterised with cairosvg once, when
this folder was made: the Pi only reads the PNGs. Flags, no emblems of airlines or makers.
