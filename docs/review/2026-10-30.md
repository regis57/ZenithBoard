### Leaner architecture (1.1), by value

1. **One source of rules for every value (A3b, and the root cause of SH1 and SH4).** Today each value is checked two or three times, and the copies already disagree. With one table (key, type, range, enum) read by the shell, the console catalogue, the presets and `settings_import`, the injection class closed in B1 cannot come back through a forgotten path.
2. **Reload the config instead of restarting the service (A2b).** It removes one restart per console change: no lost `seen` or `farthest` data, no burst of lookups to adsbdb, hexdb and Planespotters, and a page reload costs less than a service restart on a Pi 3B.
3. **One unit-conversion module per language (root cause of SO3 = A1, S3 = P3, W6).** One `units.py` used by `social.py`, `telegram.py`, `social_card.py` and `server.py`, and one JS helper shared by `format.js` and `stats.js`, checked against one table test. Today five copies exist, and each unit added so far missed one of them.
4. **One "persist on change" state helper for the posting services (SO1, SO6).** It saves after each send and on SIGTERM, shared by `social.py` and `telegram.py`, so "once per crossing" holds through any restart, in one place.
5. **A clean privilege boundary between root and `zenithboard` (SH2, C2, C4).** Root-owned data folder with the sticky bit; the service user writes only its own subfolders; the spool is `root:zenithboard 1730`; root code opens paths with `dir_fd` and `O_NOFOLLOW` only. B3 does most of this; 1.1 writes it down in Architecture.md as a rule and adds a test that walks every root-run path.
6. **One window helper for the stats reader (S4, S5).** One function decides the window start and the bucket for a row (day, hour, slot), used by `read_stats`, `stats_window`, `_with_farthest` and `read_farthest`, so the line and the box cannot drift apart again.
7. **Shared places index (A4):** load once, look up in buckets, share it between processes.
8. **Smoke test and docs coverage in CI (T1 follow-up, T8):** a page-error check, and a check that every test file is listed in Testing.md.
9. **Dead code removal (A5).**
